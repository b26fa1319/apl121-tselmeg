## 1. Төслийн зорилго

Энэхүү программ нь Даваагаас Ням хүртэлх 7 өдрийн температурыг Celsius (°C)-ээр авч дараах үйлдлүүдийг хийнэ.

- Celsius температурыг Fahrenheit (°F) рүү хөрвүүлэх
- Температурыг хүйтний ангиллаар ангилах
- Хувцасны зөвлөмж өгөх
- 7 өдрийн үр дүнг хүснэгтээр харуулах
- Хамгийн хүйтэн өдрийг олох
- Буруу оролтыг шалгаж, зөв утга орох хүртэл дахин асуух

---

## 2. Өөрийн тогтоосон дүрэм

Температурын зөвшөөрөгдөх хүрээ:

- **Доод хязгаар:** -60°C
- **Дээд хязгаар:** 20°C
- -60°C болон 20°C утгууд зөвшөөрөгдөнө.
- Бутархай температур оруулж болно.
- Хэрэв -60°C-аас бага эсвэл 20°C-аас их утга оруулбал программ зөв утга орох хүртэл дахин асууна.

Fahrenheit хөрвүүлэлтийн томьёо:

```text
F = C × 9 / 5 + 32
```

Гаралтын температурыг 1 орны нарийвчлалтай хэвлэнэ.

---

## 3. Хүйтний ангилал ба хувцасны зөвлөмж

| Celsius температур | Ангилал | Хувцасны зөвлөмж |
|---|---|---|
| 0°C болон түүнээс дээш | Warm | Light jacket |
| -10°C-аас 0°C хүртэл | Cool | Warm jacket and hat |
| -20°C-аас -10°C хүртэл | Cold | Winter jacket and gloves |
| -30°C-аас -20°C хүртэл | Very cold | Layer clothes and wear warm boots |
| -30°C-аас доош | Extreme cold | Wear very warm clothes and limit time outside |

Хэрэв хамгийн бага температур хэд хэдэн өдөр ижил байвал хамгийн түрүүнд таарсан өдрийг хамгийн хүйтэн өдөр гэж хадгална.

---

## 4. Flowgorithm алгоритм

Flowgorithm программ дараах үндсэн хэсгүүдтэй.

1. 7 өдрийн температурыг `for` давталтаар авах
2. `do-while` давталтаар оролтын утгыг шалгах
3. `&&` болон `||` логик оператор ашиглах
4. `else-if` нөхцлөөр хүйтний ангилал гаргах
5. Давталтаар хамгийн бага температурыг хайж хамгийн хүйтэн өдрийг олох
6. `PrintDayResult` гэсэн тусдаа Function ашиглах
7. Main-аас `PrintDayResult(celsius[day], day)` гэж Call хийх
8. Өдөр бүрийн Celsius, Fahrenheit, ангилал, хувцасны зөвлөмжийг хэвлэх

## 8. Заавал байх 7 элемент

Энэхүү ажилд дараах 7 элемент бүгд орсон.

1. **Оролт/гаралт** — `scanf`, `printf`
2. **Арифметик ба логик үйлдэл** — Fahrenheit томьёо, `&&`, `||`
3. **Нөхцөл** — `if / else if / else`
4. **Давталт ба хүснэгт** — `for` давталтаар 7 өдрийн хүснэгт
5. **Дэд алгоритм** — Flowgorithm дахь `PrintDayResult` Function болон Main-аас Call
6. **Хайлт** — давталтаар хамгийн бага температурыг хайх
7. **Оролтын шалгалт** — `do-while` ашиглан буруу утгыг дахин асуух
