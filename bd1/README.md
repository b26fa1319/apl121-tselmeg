Өөрийн тогтоосон дүрэм:
Зөвшөөрөх температурын хүрээ:
*Доод хязгаар: -60°C
*Дээд хязгаар: 20°C
*-60°C болон 20°C утгууд зөвшөөрөгдөнө.
*Хүрээнээс гадуур утга оруулбал дахин асууна.
*Температур бутархай тоо байж болно.

Fahrenheit хөрвүүлэх томьёо:
*Fahrenheit = Celsius * 9.0 / 5.0 + 32.0
*Гаралтыг аравтын 1 орны нарийвчлалтай харуулна.

Хүйтний ангилал:
*0°C-аас дээш буюу тэнцүү → Warm → Light jacket
*-10°C-аас дээш буюу тэнцүү → Cool → Warm jacket and hat
*-20°C-аас дээш буюу тэнцүү → Cold → Winter jacket and gloves
*-30°C-аас дээш буюу тэнцүү → Very cold → Layer clothes and wear warm boots
*-30°C-аас доош → Extreme cold → Wear very warm clothes and limit time outside

Хэрэв хамгийн бага температур хэд хэдэн өдөр давхцвал долоо хоногийн дарааллаар хамгийн түрүүнд таарсан өдрийг хадгална.

Flowgorithm:
Flowgorithm программ дараах үндсэн хэсгүүдтэй:
*7 өдрийн температур авах
*Оролтын хүрээ шалгах
*Буруу утга оруулбал дахин асуух
*Хамгийн хүйтэн өдрийг хайх
*Celsius-ийг Fahrenheit рүү хөрвүүлэх
*Хүйтний ангилал гаргах
*Хувцасны зөвлөмж өгөх
*PrintDayResult function-ийг Main-аас Call хийх
Flowgorithm-д Main болон PrintDayResult гэсэн function ашигласан.

Main дотор:
*PrintDayResult(celsius[day], day)
гэсэн Call ашиглаж тухайн өдрийн температур болон өдрийн индексийг PrintDayResult function руу дамжуулна.

PrintDayResult function нь:
*Fahrenheit утгыг тооцно.
*Өдрийн нэрийг тодорхойлно.
*Celsius болон Fahrenheit утгыг хэвлэнэ.
*Хүйтний ангилал гаргана.
*Хувцасны зөвлөмж хэвлэнэ.

C программыг ажиллуулах:
